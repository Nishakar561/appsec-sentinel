Update system and install prerequisites: Prepares Debian to download packages over HTTPS
sudo apt-get update
sudo apt-get install ca-certificates curl gnupg

Add Docker's official GPG key: Cryptographically verifies the downloads
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/debian/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg

Add the Docker repository: Dynamically targets your ARM64 architecture
echo \
  "deb [arch="$(dpkg --print-architecture)" signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/debian \
  "$(. /etc/os-release && echo "$VERSION_CODENAME")" stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

Install the Docker Engine: Installs the core daemon, CLI, and Buildx plugins
sudo apt-get update
sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin

Configure user permissions: Prevents needing 'sudo' for every Docker command
By default, the Docker daemon binds to a Unix socket owned by the root user. To run Docker commands without typing sudo every time, add your current user to the docker group:
sudo usermod -aG docker $USER

Crucial Final Step:
For the permission changes in Step 5 to take effect, you must refresh your SSH session. Type exit to close the connection to the VM, and then immediately SSH back in from your Mac terminal.
Once you are logged back in, verify the engine is running natively by typing: docker run hello-world
